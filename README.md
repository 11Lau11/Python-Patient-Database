# Python-Patient-Database

A Python terminal-based (CLI) application built for managing patient records, data validation, and basic user menu operations.

## Features
- **User Authentication & Menu System:** Interactive CLI navigation built with `while` loops and `match-case` statements.
- **Dynamic Data Storage:** Uses nested dictionaries inside a list to store patient records dynamically at runtime without data overwriting.
- **Strict Data Validation:** Validates user input (e.g., set-based checking for allowed gender formats and numerical boundary validation for birth years).

## Tech Stack
- **Language:** Python 3.13.14
- **Concepts Used:** Data Structures (Lists, Dictionaries, Sets), Control Flow, Input Validation
